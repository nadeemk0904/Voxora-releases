# Voxora

Universal AI audio assistant for Windows: meeting transcription with speaker detection, and voice dictation into any app (double-tap Caps Lock).

## Download

Get the latest build from **[Releases](../../releases/latest)**.

## Install

1. Download **`Voxora-Setup-<version>.exe`** from [Releases](../../releases/latest).
2. Double-click it and follow the steps. No administrator rights are needed.
3. Start **Voxora** from the Start menu (or tick *Start Voxora* at the end of setup).

To uninstall: *Settings → Apps → Installed apps → Voxora → Uninstall*.

## Notes

- **Windows SmartScreen:** the app is not code-signed yet. On first launch, click *More info → Run anyway* (for both the setup and the first launch).
- **Speech model:** the Whisper model downloads automatically the first time you transcribe (internet needed once).
- **AI features** (summaries, cleanup, speaker naming) need your own AI endpoint and key, entered in Settings. Transcription and dictation work without one.

## Requirements

Windows 10/11, 64-bit.
